# ⚡ Ultra-Fast Ethereum Transfer Bot

ربات هوشمند انتقال خودکار اتریوم با قابلیت‌های حرفه‌ای و سرعت بالا.

## 📁 ساختار پروژه

```
/
├── src/                          # کدهای اصلی برنامه
│   ├── bot.js                    # فایل اصلی ربات
│   ├── nonceManager.js           # مدیریت nonce تراکنش‌ها
│   ├── instanceLockManager.js    # جلوگیری از اجرای همزمان
│   ├── metricsCollector.js       # جمع‌آوری آمار و متریک‌ها
│   ├── mempoolMonitor.js         # مانیتورینگ mempool
│   ├── fileOperations.js         # عملیات فایل اتمیک
│   ├── secureErrorHandler.js     # مدیریت امن خطاها
│   └── rateLimiter.js            # محدودسازی نرخ تلگرام
│
├── tests/                        # تست‌ها
│   └── validate.js               # اسکریپت اعتبارسنجی
│
├── data/                         # داده‌های ذخیره شده (runtime)
│   ├── nonce_*.json             # فایل‌های nonce
│   └── bot.lock                 # فایل قفل
│
├── package.json                  # تنظیمات پروژه و وابستگی‌ها
├── .env                          # تنظیمات محیطی (باید ایجاد شود)
└── .env.example                  # نمونه فایل تنظیمات
```

## ✨ ویژگی‌ها

- ⚡ **سرعت بالا**: تشخیص تراکنش در کمتر از 1 میلی‌ثانیه
- 🔒 **امنیت**: مدیریت امن کلیدهای خصوصی
- 🔄 **پایداری**: سیستم failover چند RPC
- 📊 **مانیتورینگ**: جمع‌آوری آمار و متریک‌ها
- 🤖 **تلگرام**: اطلاع‌رسانی هوشمند
- 🛡️ **محافظت**: جلوگیری از اجرای همزمان چند نمونه

## 🚀 نصب و راه‌اندازی

### 1. نصب وابستگی‌ها

```bash
npm install
```

### 2. تنظیم فایل محیطی

```bash
cp .env.example .env
```

سپس فایل `.env` را ویرایش کنید و مقادیر واقعی را وارد کنید.

### 3. اجرای ربات

```bash
npm start
```

### 4. بررسی سلامت

```bash
npm run health-check
```

## ⚙️ تنظیمات مهم

### RPC URLs
حداقل یک RPC URL باید تنظیم شود. برای پایداری بیشتر، چند RPC تنظیم کنید.

### Telegram (اختیاری)
برای دریافت اطلاع‌رسانی تلگرام، باید:
1. یک ربات تلگرام با @BotFather بسازید
2. TOKEN را دریافت کنید
3. CHAT_ID را از @userinfobot بگیرید

## 🔐 امنیت

- هرگز فایل `.env` را commit نکنید
- کلید خصوصی را با دقت نگهداری کنید
- از RPC های معتبر استفاده کنید

## 📊 مانیتورینگ

ربات شامل سیستم جامع جمع‌آوری آمار است:
- تعداد تراکنش‌ها
- زمان پردازش
- آمار RPC
- خطاها و بازیابی
